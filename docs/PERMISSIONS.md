# 权限设计 V1.0

## 1. 角色

- 普通用户：未成为正式成员的注册用户
- MEMBER：普通正式成员
- VICE_MINISTER：副部长
- MINISTER：部长
- VICE_PRESIDENT：副会长
- PRESIDENT：会长
- ADVISOR：指导老师

## 2. 权限常量

建议后端集中定义：
- MEMBERSHIP_REVIEW
- ANNOUNCEMENT_MANAGE
- COMPETITION_CREATE
- COMPETITION_MANAGE
- MATCH_SCORE_EDIT
- COMPETITION_FINALIZE
- MEMBER_REMOVE
- ROLE_MANAGE

不得在各 Controller 中散落字符串角色判断。

## 3. 权限矩阵

| 功能 | 普通用户 | MEMBER | 副/正部长 | 副会长 | 会长 | 指导老师 |
|---|---:|---:|---:|---:|---:|---:|
| 注册登录 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 编辑个人资料 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 申请加入 | ✓ | - | - | - | - | - |
| 展示成员二维码 | - | ✓ | ✓ | ✓ | ✓ | ✓ |
| 查看积分/排名 | ✓* | ✓ | ✓ | ✓ | ✓ | ✓ |
| 查看比赛 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 报名比赛 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 发起约球 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 发布二手信息 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 审核加入申请 | - | - | ✓ | ✓ | ✓ | ✓ |
| 发布公告 | - | - | ✓ | ✓ | ✓ | ✓ |
| 创建比赛 | - | - | ✓ | ✓ | ✓ | ✓ |
| 编辑比赛/赛程 | - | - | ✓ | ✓ | ✓ | ✓ |
| 录入比分 | - | - | ✓ | ✓ | ✓ | ✓ |
| 最终确认赛事 | - | - | ✓ | ✓ | ✓ | ✓ |
| 移除普通成员 | - | - | ✓ | ✓ | ✓ | ✓ |
| 任命职务 | - | - | - | - | ✓ | ✓ |

\* 普通用户可以查看公开积分排行榜，但自己没有积分账户。

## 4. 后端要求

- `/api/v1/admin/**` 必须执行后端授权。
- 不能依靠前端隐藏按钮实现权限控制。
- 越权调用应返回 HTTP 403 + `PERMISSION_DENIED`。
- 所有审核、移除成员、职务修改、比赛结算操作写入审计日志。
