# 开源乓协管理系统 产品需求规格 V1.0

## 1. 产品定位

开源乓协是面向校园乒乓球爱好者与正式成员的跨端活动管理平台。

核心能力：
- 用户注册与个人资料
- 申请加入开源乓协及审核
- 成员身份二维码
- 公告
- 比赛
- 积分
- 约球
- 二手信息

客户端至少支持：
- 微信小程序
- Android App

推荐前端：HBuilderX + uni-app + Vue 3 + TypeScript + Pinia。

推荐后端：Java 21 + Spring Boot 3.5.x + PostgreSQL 17 + Redis 7.x。

## 2. 用户与成员

所有人均可注册，注册后默认是普通用户。

普通用户可：
- 查看公开公告
- 浏览比赛
- 报名允许普通用户参加的比赛
- 发起和参加约球
- 浏览与发布二手信息
- 编辑个人资料

普通用户可提交“加入开源乓协”申请。

申请资料：
- 真实姓名
- 学号
- 学院
- 专业
- 年级
- 手机号
- 申请理由（可选）

申请状态：
- PENDING
- APPROVED
- REJECTED
- CANCELLED

正式成员状态：
- ACTIVE
- LEFT
- REMOVED

审核权限：
- 副部长
- 部长
- 副会长
- 会长
- 指导老师

审核通过后：
- 创建正式成员记录
- 生成成员编号
- 创建 1400 初始积分账户
- 授予 MEMBER 角色
- 允许生成成员身份二维码

## 3. 组织职务

V1：
- MEMBER 普通成员
- VICE_MINISTER 副部长
- MINISTER 部长
- VICE_PRESIDENT 副会长
- PRESIDENT 会长
- ADVISOR 指导老师

不设置临时管理员。

成员关系与职务必须分开保存。

## 4. 成员身份二维码

用途仅为证明“当前是否为有效正式成员”。

不用于：
- 支付
- 门禁
- 签到
- 比赛检录
- 器材借用

二维码使用 60 秒有效短期 Token，不允许直接编码 userId、成员编号、学号等长期标识。

验证结果只展示：
- 姓名
- 成员编号
- 当前职务
- 成员状态
- 验证时间

## 5. 比赛性质

### DAILY 日常比赛
- 有报名、编排、比分和结果
- 不影响积分

### EXAM 考试比赛
- 面向老师或课程考试场景
- 可记录比赛成绩
- 不影响开源乓协积分
- 可导出姓名、学号、场次、胜负、排名等结果

### RATED 积分赛
只有满足以下全部条件的单场比赛才影响积分：
- competition.type == RATED
- 双方 membership.status == ACTIVE
- 结果已确认
- 不是 BYE
- 不是未开赛弃权
- rating_eligible == true

普通用户可以参加允许公开报名的积分赛，但与正式成员交手时不影响积分。

## 6. 比赛项目与赛制

V1 比赛项目：
- SINGLES 单打

V1 赛制：
- SINGLE_ELIMINATION 单淘汰
- ROUND_ROBIN 小组循环

后续预留：
- 双打
- 团体
- 小组 + 淘汰复合赛制

## 7. 比赛流程

状态：
DRAFT
→ REGISTRATION
→ ARRANGING
→ READY
→ RUNNING
→ RESULT_CONFIRMING
→ FINISHED

未结束状态可转 CANCELLED。

FINISHED 后普通业务接口不得修改比分、赛程或积分。

## 8. 比分

支持：
- 三局两胜
- 五局三胜
- 七局四胜

默认每局 11 分，至少领先 2 分。

合法示例：
- 11:0
- 11:9
- 12:10
- 15:13

非法示例：
- 10:8
- 11:10
- 12:11

## 9. 积分

所有新正式成员统一 1400 分。

积分按每一场有效对局结算，不按冠军、亚军等名次一次性加分。

V1 不考虑：
- 新人双倍
- 新人保护
- 定级赛
- 长期不比赛衰减
- 3:0 与 3:2 的不同权重

最低积分 400。

## 10. 公告

管理角色可：
- 发布
- 编辑
- 删除
- 置顶
- 设置 PUBLIC / MEMBERS_ONLY

## 11. 约球

所有注册用户可发起。

字段：
- 标题
- 时间
- 地点
- 人数
- 可选水平范围
- 说明
- 联系方式

约球永远不影响积分。

## 12. 二手信息

只做：
- 发布
- 浏览
- 联系卖家
- 编辑
- 标记已售

不做：
- 在线支付
- 订单
- 物流
- 退款
- 担保交易

## 13. V1 不做

- 双打
- 团体赛
- 即时聊天
- 在线支付
- 直播
- AI 裁判
- 多租户
- 微服务
- 消息队列
- 复杂积分定级
