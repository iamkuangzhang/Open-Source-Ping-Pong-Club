# 测试与验收计划 V1.0

## 1. 原则

核心业务没有自动化测试不得宣布完成：
- 成员审核
- 权限
- 状态机
- 单淘汰
- 小组循环
- 比分
- 自动晋级
- 积分
- 幂等
- 并发

集成测试使用 Testcontainers PostgreSQL，不使用 H2 代替关键数据库行为。

## 2. 积分单元测试

至少覆盖积分差边界：
0, 12, 13, 37, 38, 62, 63, 87, 88, 112, 113, 137, 138, 162, 163, 187, 188, 212, 213, 237, 238, 1000

每个边界至少：
- 高分者胜
- 低分者胜

额外：
- 1400 vs 1400
- 400 下限
- 404 下限
- 对称性

## 3. 单淘汰

人数：
2, 3, 4, 5, 7, 8, 9, 13, 16, 17, 31, 32, 33, 64

验证：
- bracketSize
- BYE 数
- 首轮每人最多出现一次
- BYE 自动晋级
- 非决赛存在 next_match
- 最终冠军只有一个

## 4. 随机可复现

相同：
- participants
- randomSeed

执行 100 次应产生相同结果。

## 5. 小组循环

人数：
3, 4, 5, 6, 7, 8

验证：
- 总场数 n(n-1)/2
- 每两人恰好交手一次
- 一轮内同一用户最多一场

## 6. 比分

合法：
- 11:0
- 11:9
- 12:10
- 15:13

非法：
- 10:8
- 11:10
- 12:11

验证 best_of 5：
一方三胜后自动结束。

## 7. 状态机

测试所有合法转换。

必须拒绝：
- DRAFT → FINISHED
- FINISHED → RUNNING
- FINISHED → CANCELLED
- REGISTRATION → RUNNING
等非法跳转。

## 8. 权限

至少覆盖：
- 普通用户
- MEMBER
- MINISTER
- PRESIDENT
- ADVISOR

示例：
普通用户 POST `/admin/competitions` → 403  
MINISTER → 成功  
MEMBER 审核成员 → 403

## 9. 幂等

重复执行：
- 比赛报名
- 成员审核
- 约球加入
- 比赛 finalize

finalize 连续请求 10 次：
积分只能结算一次。

## 10. 比分并发

两个请求都携带相同 version 修改同一 Match：
- 一个成功
- 一个 HTTP 409 `MATCH_VERSION_CONFLICT`

## 11. 积分并发

两个结算流程涉及相同用户时：
- 不得丢失更新
- 不得重复流水
- 最终账户应与流水重放结果一致

## 12. Ledger 完整性

测试辅助函数：
`rebuildRatingFromLedger(userId)`

从 INITIAL 顺序应用所有流水，最终值必须等于：
`rating_accounts.current_rating`

## 13. 成员二维码

验证：
- ACTIVE 可生成
- 普通用户不可生成
- 60 秒后过期
- 成员退出/移除后旧 Token 不应再验证为有效身份
- 验证接口不得返回手机号、微信号、QQ、完整学号

## 14. 性能

k6 至少：
- 100 VU
- 5 分钟

典型：
- 登录
- 首页
- 比赛列表
- 比赛详情
- 排行榜
- 公告

目标：
- 错误率 < 1%
- 普通读取接口 P95 < 500ms（作为工程目标）
- 无数据错误

## 15. 数据规模

生成：
- 5000 users
- 1000 active members
- 100 competitions
- 10000 matches
- 50000 rating_ledger
- 1000 market_posts

检查：
- N+1
- 主要列表查询
- 必要 EXPLAIN ANALYZE

## 16. 最终核心验收

### 入会
普通用户 → 申请 → 审核 → ACTIVE → 1400 → 可生成二维码

### 淘汰赛
8 人 → 抽签 → 8 强 → 半决赛 → 决赛 → 冠军

### 小组
4 人 → 6 场 → 正确排名

### 积分
1400 vs 1400 → 1408 / 1392

### 爆冷
1600 vs 1400，低分胜 → 1560 / 1440

### 日常/考试比赛
不得改变 Rating

### 正式成员 vs 普通用户
不得改变 Rating

### finalize 重复提交
只能结算一次

### 并发比分
旧 version 不能覆盖新结果
